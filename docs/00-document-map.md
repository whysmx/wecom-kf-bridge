## 优先级与维护

用户最新明确要求 > 现行需求/架构决策 > 对应协议契约 > 架构与实施计划 > 示例。文档相互冲突时直接修改相关正文，不保留互相覆盖的旧版/新版条款，不另写修改记录。文件按主题拆分，不表示需要实现多套方案或多个服务。

管理操作不要求建设通用 API 平台，逻辑数据实体也不要求逐一建表。“项目小”不允许略过真实账号 CRUD、鉴权、事务、人工栅栏和 >95% 覆盖率；“单进程”不允许变成所有客户轮流等整轮 AI 完成。

测试文档、业务验收矩阵与兼容边界验收共同使用，覆盖 AT-001～AT-070，均为待执行；没有“文档写了测试”即通过的含义。任务及测试报告模板可简短填写，不构成额外项目管理系统。

必要的源码 SHA、接口核验日期及运行版本仍保留用于可复现性，不属于旧产品文档。Git 自带提交历史保留，不要求重写。

## 证据等级

- **用户要求/设计约定**：说明产品需要，不是外部 API 事实。
- **固定源码事实**：必须有提交及文件/函数定位；不能外推到全部版本。
- **SDK 注释/项目文档**：可帮助设计和交叉比对，不代表腾讯当前权限或配额。
- **官方/企业核验**：标明适用账号范围、日期、字段与限制；真实效果另附测试记录。
- **已验证实现**：需要实际版本、命令、环境和报告。fake 不是官方沙箱。

## 术语及最短路径

客服账号是 `open_kfid`，客户是 `external_userid`，不是企业员工 userid；昵称只显示。真实微信令牌、兼容令牌、回调签名 Token、通知拉取 token 各自独立。绑定连接一个客服与一个客户端 HTTP 平台实例；代际 UID 防止旧 AI 回复复活，不保证文件权限隔离。UNKNOWN 表示不能证明成功或失败，不等于可安全重试。

单进程只指网关运行一个服务进程；该进程可并发处理多个客户。cc-connect 与 Codex 是独立执行端。worker 数限制对应网关任务的同时执行数量，不限制可存在的客户和会话数量；实际生成并发还须验证执行端容量及限制。
