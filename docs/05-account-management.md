# 客服账号管理详细设计

> v0.1。满足“还要实现客服账号管理”；不是只配置 open_kfid，也不是把客户资料查询当账号管理。

## 1. 管理对象分层

| 对象 | 来源 | 本产品操作 |
|---|---|---|
| 真实客服账号 | 微信客服，标识 open_kfid | 同步、创建、编辑、删除、接入链接 |
| 接待人员 | 企业微信成员 | 查看可选接管目标、必要状态验证；不做员工通讯录管理 |
| 客户 | 个人微信 external_userid | 昵称缓存/诊断，不创建或删除微信客户 |
| 网关绑定 | 本地配置 | 目标回调、虚拟凭证、启停、修订、测试 |

真实账号操作只在官方权限允许的范围内执行。所有入口须显示“修改微信侧”还是“仅修改网关”。

## 2. 列表与同步 R-011

中文列表显示头像、客服名称、open_kfid、所属企业、微信侧可见/权限状态、网关转发状态、绑定项目标签、回调健康、最近同步时间和最近错误。

按企业分页从官方同步，使用 `(tenant_id, open_kfid)` upsert；保留本地备注、回调、密钥及启停配置。必须区分完整同步、部分同步与失败。某页失败时不得把其他未返回账号当成删除；一次完整列表中缺失也可能是权限收回，先标记“不可见/待核查”，不能直接删除本地状态。

支持名称/open_kfid/状态筛选、本地分页、单账号刷新和企业全量同步。空列表只有在完整成功同步时才能显示“暂无可见账号”，不能把网络错误渲染成空列表。

## 3. 创建真实客服 R-012

流程：选择已授权企业 → 输入名称 → 上传/选择符合官方规则的头像 → 预览 → 明确确认创建 → 后台记录 operation → 调用官方 add → 保存返回 open_kfid → 回读/同步 → 展示成功结果 → 引导配置 cc-connect 绑定。

必需字段、字符长度、头像格式/大小取官方已核实约束，不写死未经证实的限制。若当前官方要求头像而用户未提供，应提示上传，不伪造 media_id。

创建前生成独立 `Idempotency-Key`；同一键+同一规范化参数返回同一操作结果，参数不同返回冲突。网关内部幂等不自动让官方 add 幂等。外部响应丢失时标 UNKNOWN，不自动再建一个。管理员先同步/核查后关联已有 open_kfid 或明确重试；不能用同名匹配直接认为是同一个账号。

创建后默认“未绑定、AI 转发停用”，防止意外把新客户消息发到其他项目。

## 4. 编辑真实客服 R-013

详情页展示微信当前资料与待修改资料。仅允许修改官方支持字段，如名称/头像；open_kfid、真实企业归属不可编辑。后台记录变更前后摘要和 revision，外部成功后更新本地资料。

超时、权限撤销、头像过期和并发编辑分别反馈；本地不得先显示“已保存到微信”再异步失败。乐观并发控制失败返回 409/版本冲突，要求刷新确认，不能后写覆盖前写。

本地备注/项目标签编辑不得调用官方 update，应在 UI 清楚区分。

## 5. 删除真实客服 R-014

危险操作必须显示企业、名称、open_kfid、绑定状态及删除真实微信账号的后果。要求重新确认账号标识/名称和一次性确认票据；不能只用默认选中的复选框。首版不提供批量删除。

建议序列：创建待确认 operation → 本地暂停新转发并封锁旧 UID → 处理未完成任务/提示风险 → 调用官方删除 → 明确成功后标 tombstone、撤销绑定令牌、保留最小审计 → 核查列表状态。

未知结果保持“删除结果待核实、已暂停转发”，不能自动恢复 AI，也不能重建同名账号来“回滚”。失败要告诉管理员微信账号是否仍可见，不自动删除本地证据。

删除、解绑、停用是不同操作：

| 操作 | 删除微信账号 | 删除资料/审计 | 停止 AI |
|---|---|---|---|
| 停用转发 | 否 | 否 | 是 |
| 解绑 cc-connect | 否 | 保留记录 | 是 |
| 删除微信客服 | 是，官方确认后 | 按保留策略 | 是 |

## 6. 客服链接 R-015

在账号详情通过已核实的官方接口生成/获取客服接入链接；可选择业务场景参数，但须按官方允许范围验证。显示链接目标账号，可复制，可选本地生成二维码以呈现该链接。

链接不是智能机器人登录二维码，不创建个人微信登录态。接口返回错误不得生成一个猜测 URL。二维码内容必须与显示链接一致；使用有审计记录的账号身份操作。链接中可能包含场景信息，不能将 Secret、access_token、客户 ID 放入二维码。

## 7. 绑定 cc-connect R-016

绑定表单：账号只读、项目显示标签（不负责创建项目）、完整 callback_url、虚拟 corp_id、数字 agent_id、独立 corp_secret、回调 Token/AES Key、凭证版本、启停状态、允许的回调网络目标。

新建绑定时生成凭证，不让用户复制真实企业微信 Secret。检测 active binding 唯一、agent_id 与令牌范围一致、callback_url 不被意外共享。为现有 WeChat Work 表单输出一页逐字段配置说明及可选 TOML；查看/下载密钥需再次认证，正常列表掩码显示。

绑定验证用加密 echostr GET，不触发 AI。必须显示 DNS/TLS/签名/解密验证各阶段结果，不以网关 → 官方可通替代网关 → cc-connect 可通。

同一 cc-connect 主机多个平台实例使用不同监听端口；网关不能代替用户占用/分配目标机器的端口，只能提示并检测可观察冲突。

## 8. 启停、改绑与轮换 R-017

停用立即禁止新 AI 转发及出站回答，继续保存必要事件/官方状态。待处理客户消息默认标记 held_disabled，恢复后不自动把历史全部补送；管理员明确选择仍在有效期内的记录重放。超过窗口的记录不改时间冒充新消息。

改绑时先暂停、冻结旧 revision 与 UID、验证新目标，再启用新 revision。旧任务不能改投新目标，新会话从新代际开始。

虚拟密钥轮换要说明客户端令牌有缓存；可采用短过渡期接受旧版本或维护窗口同步更新/重启。回调 AES Key 的更换必须与 cc-connect 同步，旧密钥不得无限期有效。真实企业微信密钥轮换独立于虚拟密钥，不能混同。

## 9. 接管相关管理

可显示客服当前接待状态、可用接待人员（有权限时）并发起显式转人工/恢复操作。真实状态转换由官方接口确认，网关停用按钮不能显示成“人工已接待”。不开发人工聊天、排班、工单或全量通讯录。

## 10. 验收

模拟分页/部分失败/权限变化；真实测试账号完成增改查删和链接；外部创建成功响应丢失不重复创建；客户端绑定配置零代码改动通过；暂停不删除账号；跨企业/跨绑定令牌无法查看或发送；全部操作有脱敏审计；测试覆盖 R-011～R-018。
