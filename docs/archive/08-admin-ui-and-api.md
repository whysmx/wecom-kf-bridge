# 中文管理页面与内部操作合同

> 当前最终设计。这里定义需完成的管理行为，不要求先交付一套公共 REST 平台。依[架构决策](adr/0001-design-baseline.md)，优先同进程服务端渲染 HTML 和普通表单。

## 1. 页面范围

只做企业配置、客服账号列表/详情、绑定与凭证、消息/人工状态诊断、操作审计。概览可放在列表顶部，不单建分析仪表盘。单企业、单管理员角色即可，不增加租户注册、复杂 RBAC、工单、排班或坐席聊天。单管理员角色是后台权限模型，不限制客户并发对话。

管理端只监听本机/受控管理网络，使用受保护管理员会话。**所有管理读取也必须鉴权，包括概览、状态、诊断和操作记录**；只有最小、不含配置/业务信息的健康探针可独立公开。兼容 access_token 不能登录后台。

## 2. 必需操作

| 页面/对象 | 必需行为 |
|---|---|
| 企业配置 | 保存真实凭证、测试读权限、显示回调配置与实际授权范围 |
| 客服账号 | 同步真实列表、搜索/分页、创建、编辑名称/头像、明确二次确认后删除 |
| 账号详情 | 官方客服链接/可选二维码、本地备注、API 可见性、绑定状态 |
| 绑定 | 配置回调、生成虚拟凭证、加密挑战验证、逐字段复制/TOML 导出 |
| AI 转发 | 停用、恢复、解绑、改绑、轮换；与删除微信账号明确区分 |
| 接管 | 显示官方状态及本地暂停；显式转人工/新代际恢复；必要时只读接待人员列表 |
| 诊断 | Inbox/Outbox、部分发送、UNKNOWN、后续失败及需人工处置的历史记录 |
| 审计 | 操作者、对象、版本、结果、时间；不展示密钥和默认完整客户正文 |

真实账号 CRUD 必须调用官方接口，详细行为遵守[账号管理](05-account-management.md)。不能将轻量实现解释成取消真实账号操作，或只做一个本地 open_kfid 配置列表。

## 3. 表单/内部接口规范

可以使用 `/admin/api/v1` 作为内部路径前缀，但逐端点拆分不是必须实现的公共 API 合同。页面与处理器按上述操作实现即可，不要求 OpenAPI 平台、独立 SPA、通用 SDK、自动化管理令牌或 opaque cursor 框架；小列表用 page/limit 即可，资源上限可配置且不代表业务账号上限。

UTF-8，内部时间 UTC RFC3339，页面可按配置时区显示。使用成熟会话/密码处理方案，不自创认证协议；Cookie 设置 HttpOnly、适用的 Secure/SameSite，写入验证 CSRF 和对象范围。公网不用明文 HTTP 管理。

表单携带当前 revision 及随机单次操作键。并发变更冲突固定返回 409 并要求刷新；同键同参数返回原结果，不再调用微信，同键不同参数拒绝。删除在危险区域显示企业、名称、open_kfid 和影响，确认票据绑定对象/动作/revision/短有效期并只可用一次，不能仅凭 `confirmed=true` 执行。

客户端禁用按钮只能改善体验，服务端仍做幂等和授权。头像通过受控 asset_id 上传，不接受服务器文件路径或任意 URL 下载。callback_url 的连接测试和保存都用同一 SSRF allowlist。

## 4. 同步优先，未知可查

创建/修改/删除/绑定验证等通常在有界请求内同步完成：登记 operation → 调用外部/本地操作 → 保存结果 → 显示确定结果。以 Post/Redirect/Get 或等价方式避免刷新重交；不必所有操作都返回 202 再轮询。“同步完成”仅指当前管理请求等待自身结果，不得持全局锁阻塞客户收发。

确需后台处理的完整列表同步可返回待处理状态，在同一页面刷新结果即可。若使用 202，只说明已登记；绝不说明微信账号已创建。不要为此开发通用异步操作调度器。

外部可能成功但响应丢失时显示“结果待核实，已暂停相关自动操作”。保留 operation_id，可同步官方列表并人工关联已知账号；不能用同名直接认为同一账号或点击刷新即重新创建。操作记录、删除暂停和 UNKNOWN 保留规则不变。

不提供一键批量重放未知客户消息。重试入口先说明是否确定未执行，若可能重复必须显式确认；不改原 MsgId/时间，也不把旧任务改投新绑定。

## 5. 配置、凭证与显示

现有 cc-connect 字段逐项显示，api_base_url 在高级配置，callback_url 是网关访问客户端的地址。配置导出仅含虚拟凭证，不含真实微信 Secret。密钥首次生成可一次显示，之后掩码；重新导出需要再次认证、禁止缓存并记审计，不放 URL/localStorage/第三方脚本。

明确区分微信账号资料与本地备注、官方接待状态与本地暂停、服务存活与消息处理状态。人工恢复页面提示新代际会新建客户端上下文；HTTP_ACCEPTED 不显示已回答，UPSTREAM_ACCEPTED 不显示已读。

昵称是文本，HTML 安全转义；昵称刷新提示客户端可能仍使用缓存。所有页面保持中文、标签清晰、键盘可操作，载入/空列表/失败/部分完成/UNKNOWN 分别展示。窄屏可用即可，不另做移动应用。

## 6. 测试

验证真实 CRUD、重复提交、刷新、revision 冲突、CSRF、所有读取的鉴权、篡改对象 ID、删除确认、未知结果不重发、XSS、凭证脱敏、回调测试不触发 AI。前端 >95% 约定适用于自行编写的业务脚本；纯 HTML/CSS 不计代码覆盖，但仍做页面流程测试。优先少写前端业务脚本，不以把业务移到未统计代码来规避覆盖。
