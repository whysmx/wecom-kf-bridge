# 技术可行性与兼容边界

> 当前最终设计 · 2026-10-09。结论基于固定源码检查；未运行网关、cc-connect、Codex 或真实微信接口。

## 1. 结论

**主路线有源码支持，适合以单网关进程并发服务多个客户；不能据此宣称已稳定运行或完成官方联调。** 微信客服 → 独立网关 → 未修改的 cc-connect WeCom HTTP 适配器 → Codex。上游支持 api_base_url，网关必须同时实现兼容 API 和反向加密 XML 回调，不是透明 URL 代理。

采用单企业、单实例、单网关进程、SQLite、少量有界后台任务、同进程中文管理页。单进程只限定网关部署方式，不要求所有客户轮流等待 AI；不同客户会话独立，cc-connect/Codex 为独立执行端。实际端到端并发需验证同项目、不同项目、慢任务与容量边界，不能只凭 goroutine 数宣称已通过。

真实客服账号管理、昵称、人工接管、媒体、身份隔离和 >95% 测试要求完整保留。[架构决策](adr/0001-design-baseline.md)规定唯一实现基线；[业务验收矩阵](13-acceptance-matrix.md)包含 AT-070 多客户并发验收。

## 3. 必须落实的约束

| 主题 | 已核对的行为或风险 | 实现要求 |
|---|---|---|
| 接待人员列表 | WxJava 使用 GET | GET /cgi-bin/kf/servicer/list，open_kfid 放查询参数；权限待联调 |
| 回调响应 | HTTP 200 先于解析/过滤/handler | 只标 HTTP_ACCEPTED，不标已回答；没有回复不是盲重投依据 |
| 旧消息 | 比较进程 StartTime 减 2 秒，不是当前时间减 2 秒 | 保留原 CreateTime；重启历史问题保守暂停，不伪造已过期或已处理 |
| 短期去重 | MsgId 约 60 秒进程内缓存，重启丢失 | 网关独立持久化；DELIVERY_UNKNOWN 默认不自动重发 |
| 分段发送 | Reply 每 2000 UTF-8 字节分块，中间提示也可能发送 | 关闭非必要提示；所有段落和图片计入预算，不假定一问一请求 |
| 客服窗口/条数 | SDK 注释记录 48 小时及最多 5 条条件 | 实际企业确认 policy；处理部分发送，不能外推为每个 AI 回答各获一份额度 |
| UNKNOWN | 可选 msgid 未证明重试幂等；sync 不返回 API 成功发送消息 | 不盲重发，不用“未同步到”认定未发送；后续失败事件独立登记 |
| 人工接管 | 完整接管/结束周期可能在事件迟到前发生 | 持久化暂停和代际；缺口保守暂停，旧 UID 不复活，说明在途竞态 |
| 命令权限 | 部分 cron/commands 操作不要求管理员 | 客户入口限制控制命令/别名，客户端纵深限制；不靠空 admin_from 保证安全 |
| 只读与文件 | 只读仍可读取同账户有权限的资料 | exec+suggest、低权限账户、只读公共资料；敏感客户文件先验证隔离 |
| 持续会话 | 稳定 UID 不阻止客户端闲置重置 | 连续问答显式 reset_on_idle_mins=0，人工新代际仍新建上下文 |
| 媒体 | 图片固定标 image/jpeg，下载不检查 HTTP 状态 | 投递前取好并验证字节/MIME；非 200 空体不保证没有空附件 |
| 实施边界 | 管理、任务和数据拆分容易被泛化为平台 | 简单表单/SQLite/同进程任务，人工暂停和权限先于对外文本试用 |
| 多客户并发 | 单进程本身不是客户数限制；执行端容量尚未实测 | 不持全局锁等整轮 AI；不同客户独立调度，局部状态串行，容量有界；执行 AT-070 |

涉及权限、错发、丢失或客户并发的约束属于验收要求，不因项目规模小而省略。

## 4. 能力判断与剩余限制

文本双向、客户身份映射、昵称查询兼容、真实账号 CRUD/链接均有对应接口或源码路径，未发现主路线需要修改 cc-connect 的结构性障碍。人工接管可以抑制发送，不能通过当前 HTTP 协议取消已运行的 Codex，也不能撤销已提交到微信的消息。代际切换会新建客户端上下文。

持久化保证网关内部消息/游标一致性，不是端到端 exactly-once。未知发送、回调接受后客户端崩溃、重启过滤、媒体下载失败和平台限制必须可见。昵称刷新不等于客户端即时更新；UID 区分会话不等于 OS 文件隔离。

语音/文件/图片按两侧实际能力交集逐项上线；未通过异常路径和真实解码验证的类型保持关闭，明确未完成，不能因此宣称 R-008 已验收。多客户并发同样需要实际运行证据，不因架构图允许并发就标完成。
